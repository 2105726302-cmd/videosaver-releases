# 视频收藏家

可直接安装的 Windows 视频保存与本地素材管理工具，支持 Windows 10 / 11 64 位。

**[下载最新版安装包](https://github.com/2105726302-cmd/videosaver-releases/releases/latest)**

安装包包含运行组件，无需另外安装 Python 或 FFmpeg。下载 EXE 后双击安装，从桌面“视频收藏家”打开。

## 自动更新

首次需要安装 1.5.0 或更新版本。1.4 及更早版本需要手动安装一次新包。

软件默认在启动后及运行期间约每四小时检查新版，后台下载完成后，正常退出软件即可安装，下次打开使用新版。也可点击“重启更新”。正在保存文件时会阻止立即重启，完成任务后再点击即可。

偏好设置中可以手动检查或关闭自动更新。自动更新需要能够访问 GitHub；离线或连接失败时可以继续使用当前版本，联网后再检查。各人的保存目录、收藏备注、队列及浏览器资料保留在各自电脑上。

## 当前功能

- 从分享文案识别链接，批量加入队列并在内置浏览器打开。
- 接收网页实际发起的下载，查看进度和保存记录。
- 本地视频、图片及音频管理，缩略图卡片与列表切换。
- 内置播放、视频截图、收藏、标签备注、统一搜索与链接导出。

当前版本不自动解析所有平台的隐藏视频地址，也不自动去除水印；下载内容取决于网页提供的文件。

此仓库用于分发安装包、更新说明和签名更新清单。
